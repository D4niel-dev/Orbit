Everything you need to chat privately

Orbit connects directly — no accounts, no servers, no logs. Just you and the people you're talking to.

Peer-to-Peer

Messages go directly between devices over the local network. No intermediary servers, no central points of failure.

End-to-End Encrypted

Every message is encrypted on your device and decrypted only on your recipient's. Not even we could read them.

File Sharing

Share photos, documents, and files directly over P2P. No size limits, no upload speed caps — just fast local transfers.

Group Chats

Create group conversations with everyone on the same network. Collaborate, share, and chat in real-time.

Privacy Mode

Go invisible when you want. No read receipts, no typing indicators, no online status — total control over your presence.

Cross-Platform

Available on Windows, macOS, Linux, and Android. Orbit runs everywhere, so you can chat across all your devices.

How It Works

Getting started takes seconds. No account creation, no configuration — just install and connect.

1

Install Orbit

Download the app for your platform from our GitHub releases. Works on Windows, macOS, Linux, and Android.

2

Connect to a Network

Join any Wi-Fi or local network. Orbit automatically discovers other users running the app nearby.

3

Start Chatting

Orbit connects you instantly. Send messages, share files, and create group chats — all without internet access.

Built for Speed and Privacy

Engineered from the ground up with performance, security, and offline-first architecture in mind.

Node.js + Electron

Desktop

Cross-platform desktop app built with Electron and Node.js for native-level performance and a smooth UI experience across all operating systems.

Capacitor + Android

Mobile

Native Android experience via Capacitor, bringing Orbit to your pocket with full access to device networking capabilities.

P2P Protocol

Core

Proprietary lightweight peer-to-peer protocol designed for low-latency local messaging with automatic peer discovery.

SQLite Storage

Data

All messages stored locally using SQLite. Your data stays on your device — no cloud backups, no server-side copies.

Real-Time

Performance

Sub-millisecond message delivery over local networks. No polling, no latency — just instant P2P communication.

Open Source

Community

Fully open source under an MIT license. Audit the code, contribute features, and trust that there are no backdoors.
