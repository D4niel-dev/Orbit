# Orbit Website

The official website for **Orbit** — a modern local-first, peer-to-peer messaging platform.

🌐 **Live Website:** https://d4niel-dev.github.io/Orbit/

This repository contains the source code for the Orbit GitHub Pages website, including the landing page, documentation, download links, release information, and future developer resources.

---

## Purpose

The Orbit website serves as the central hub for everything related to the project.

It provides:

- 📥 Download links for the latest releases
- 📚 Documentation and user guides
- 📝 Release notes and changelog highlights
- 🗺️ Development roadmap
- 🔌 Plugin & Module documentation (planned)
- 👨‍💻 Developer resources
- ❓ Frequently Asked Questions
- 🔗 Links to the official GitHub repositories

Unlike the main Orbit repository, this repository **does not contain the desktop or mobile application source code**.

Current website features include:

## Development

Clone the repository:

```bash
git clone https://github.com/D4niel-dev/Orbit-Website.git
cd Orbit-Website
```

Since the website is completely static, no backend or build tools are required.

Simply open `index.html` in your browser or use a local development server.

Example:

```bash
python -m http.server 8000
```

or

```bash
npx serve .
```

---

## Deployment

The website is automatically deployed using **GitHub Pages**.

Any changes merged into the deployment branch are published automatically.

No manual deployment steps are required.
